# Учебная практика 2.26

Репозиторий содержит серию учебных заданий, разбитых по этапам разработки небольшого веб-приложения (расчёт скидок, работа с БД, интерфейс и его наполнение).

## Структура проекта

- `1) Разработка ядра бизнес-логики (Расчет скидки)/` — модуль расчёта скидок (`discount.js`) и тесты к нему (`discount.test.js`).
- `2) Интеграция с БД и агрегация данных (SQL + Backend)/` — работа с базой данных партнёров (`db.js`, `partnerService.js`) и демонстрационный скрипт (`demo.js`).
- `3) Разработка интерфейса (UI) по руководству по стилю/` — статическая верстка интерфейса (`index.html`, `styles.css`, `resources/`).
- `4) Наполнение интерфейса, отладка и стресс-тестирование/` — серверная часть (`server.js`) и клиентское приложение (`public/`), связывающее интерфейс с данными.

## Запуск

Каждый этап — отдельный подпроект. Для запуска тестов ядра бизнес-логики:

```bash
cd "1) Разработка ядра бизнес-логики (Расчет скидки)"
npm test
```

Для запуска сервера с интерфейсом:

```bash
cd "4) Наполнение интерфейса, отладка и стресс-тестирование"
node server.js
```
